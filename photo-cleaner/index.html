写真メタデータ削除ツール

フォルダ内の写真・動画から、位置情報(GPS)・撮影日時・カメラ/レンズの機種名・シリアル番号・作成者などの情報を削除します。 処理はすべてこのブラウザの中で行われ、ファイルがインターネットに送信されることはありません。

1フォルダを選ぶ

未選択

サブフォルダの中のファイルも対象になります。対応形式: JPEG / PNG / WebP / HEIC・HEIF・AVIF / MP4・MOV・M4V・3GP

このブラウザはフォルダへの直接保存に対応していないため、処理結果は ZIP ファイルでダウンロードします。 フォルダに直接保存したい場合は、パソコン版の Google Chrome または Microsoft Edge で開いてください。

2確認する(任意)

ファイルは変更しません。どんな情報が入っているかを一覧に表示します。

3削除して保存する

写真の向き(縦・横の回転情報)だけは、表示が崩れないよう残します。画像・映像のデータ自体には手を加えないので、画質は劣化しません。

結果

ファイル形式見つかった情報状態
