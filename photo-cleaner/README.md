# 写真メタデータ削除ツール

フォルダを選ぶだけで、その中（サブフォルダを含む）の写真・動画から個人情報につながるメタデータを削除するツールです。
インストールは不要で、ブラウザで `index.html` を開くだけで使えます。

**処理はすべてブラウザの中で行われ、ファイルがインターネットに送信されることはありません。**
（ページには通信を禁止する設定 `connect-src 'none'` を入れています。）

## すぐに使う(インストール不要)

claude.ai 上で公開した版を、ブラウザで開くだけで使えます(パソコン・スマートフォン両対応):
https://claude.ai/artifact/GSb3fK3Rc5PWL4NuU5G37i

この版では処理結果を ZIP(1 件だけのときはそのファイル)で保存します。
フォルダに直接書き出したい場合は、下の手順で `index.html` を Chrome / Edge で開いてください。
公開版を更新するときは `node photo-cleaner/build-artifact.mjs` で 1 ファイルにまとめた HTML を作ります。

## 使い方

1. `photo-cleaner/index.html` をダブルクリックし、ブラウザで開きます。
   - フォルダに直接保存したい場合は、パソコン版の **Google Chrome** または **Microsoft Edge** を使ってください。
   - Safari / Firefox では、処理結果を ZIP ファイルでダウンロードします。
2. 「フォルダを選択…」で写真のフォルダを選びます。
3. （任意）「含まれている情報を確認」で、各ファイルに何が入っているかを一覧で確認できます。ファイルは変更しません。
4. 保存方法を選んで「メタデータを削除」を押します。
   - **別のフォルダに保存（おすすめ）**: 元のファイルは残したまま、選んだ保存先にフォルダ構成ごと書き出します。
   - **元のファイルを上書き**: 元に戻せないので、必要ならバックアップを取ってから実行してください。
   - **ZIP でダウンロード**: 非圧縮の ZIP にまとめます（合計 4GB まで）。

保存する前に、処理後のファイルをもう一度解析して、情報が残っていないことを確認しています。
残っていた場合はそのファイルを保存せず、エラーとして表示します。

## 削除する情報

| 形式 | 削除するもの |
| --- | --- |
| JPEG | EXIF 全体（GPS位置情報、撮影日時、カメラのメーカー・機種名、**レンズのメーカー・機種名**、カメラ/レンズのシリアル番号、所有者名、作成者、著作権、ソフトウェア、メーカーノート、サムネイル）、XMP、IPTC/Photoshop 情報、コメント、MPF、その他のメーカー独自データ、画像の後ろに付いたデータ（モーションフォトの動画部分など） |
| PNG | tEXt / zTXt / iTXt（作成者・コメント・XMP など）、eXIf、tIME |
| WebP | EXIF、XMP |
| HEIC / HEIF / AVIF（iPhone の写真など） | EXIF、XMP（中身を空のデータで上書き） |
| MP4 / MOV / M4V / 3GP（スマホ・カメラの動画） | 位置情報、メーカー・機種名、ソフトウェア、作成者、撮影日時などのメタデータ（`meta` / `udta` / `uuid`）、動画・トラックの作成/更新日時、GPS などの時系列メタデータトラックの中身 |

### 画像の大きさ(縮小・圧縮)

手順 3 の「画像の大きさ」で、メタデータの削除と同時に写真を縮小・圧縮できます。

| 設定 | 長辺 | 画質 | 用途 | 1 枚の目安 |
| --- | --- | --- | --- | --- |
| 縮小しない | — | — | メタデータの削除のみ(既定) | 元のまま |
| 保存用 | 3500px | 85 | A4 全面の印刷・プレゼン資料 | 1.5〜3MB |
| プレゼン用 | 1920px | 85 | 全画面のスライド | 0.4〜0.8MB |
| ホームページ用 | 1600px | 80 | ホームページの大きな写真 | 0.2〜0.5MB |
| サムネイル | 800px | 75 | 一覧・小さな画像 | 30〜100KB |
| カスタム | 100〜20000px | 30〜100 | 自由に指定 | — |

- 指定より小さい写真は拡大しません。容量が減らない場合は元の画像のまま(メタデータの削除のみ)にします。
- 写真の向きは画像に反映してから縮小するので、縦向きの写真もそのまま正しく表示されます。
- JPEG は JPEG、PNG は PNG(透明部分を保持)、WebP は WebP のまま保存します。PNG は画質の設定が効かないため、縮小で容量が増える場合は元の大きさのままにします。
- HEIC は JPEG(拡張子 .jpg)に変換して縮小します(下の「HEIC を JPEG に変換」を参照)。
- 動画は縮小しません。
- 「撮影日時を残す」「位置情報を残す」を選んでいる場合は、縮小後の画像にもその項目だけを付け直します。
- 選んだ設定はブラウザに記憶されます。

### HEIC を JPEG に変換

「HEIC を JPEG に変換する」(既定でオン)を選ぶと、iPhone の写真(HEIC)を JPEG で保存します。
Windows のパソコン、ホームページ、プレゼン資料などでそのまま使えるようになります。

- どのブラウザでも変換できます。Safari 以外は HEIC を読み込めないため、同梱の
  [libheif-js](vendor/libheif-js/README.md)(LGPL-3.0)で読み込みます。インターネット接続は不要です。
- 「縮小しない」のときは元の大きさのまま画質 90 で、縮小を選んだときはその設定で変換します。
- 写真の向き(回転・反転)を反映し、iPhone の広い色域(Display P3)は一般的な sRGB に変換します。
- 「撮影日時を残す」「位置情報を残す」を選んでいる場合は、変換後の JPEG にもその項目だけを付け直します。
- 「元のファイルを上書き」では形式を変えられないため変換しません。別のフォルダに保存するか ZIP で保存してください。
- オフにすると HEIC のまま保存します(メタデータの削除のみ)。

### 撮影日時を残すオプション

「撮影日時を残す」にチェックを入れると、撮影日時だけを残し、それ以外(位置情報・機種名・レンズ名など)は削除します。
写真アプリで日付順に並べたいときなどに使ってください(チェックの状態はブラウザに記憶されます)。

| 形式 | 残す日時 |
| --- | --- |
| JPEG / PNG / HEIC | 撮影日時(DateTimeOriginal)とデジタル化日時(CreateDate)。タイムゾーンや秒未満の情報は削除 |
| WebP | 撮影日時(拡張形式の WebP のみ。シンプル形式の WebP には日時を入れられないため削除されます) |
| MP4 / MOV | 動画の作成・更新日時(mvhd/tkhd/mdhd)。iPhone 独自のタイムゾーン付き撮影日時は、位置情報と同じ場所にあるため削除されます |

### 位置情報を残すオプション

「位置情報を残す」にチェックを入れると、撮影場所の緯度・経度・高度だけを残し、それ以外(機種名・レンズ名・シリアル番号など)は削除します。
「撮影日時を残す」と同時に使えます。写真を見た人が撮影場所を知ることができるため、人に渡す写真や SNS に載せる写真では外してください。

| 形式 | 残す位置情報 |
| --- | --- |
| JPEG / PNG / WebP / HEIC | EXIF の GPS 緯度・経度・高度(GPS の時刻・速度・方角などは削除) |
| MP4 / MOV | 位置情報の項目(iPhone の位置情報、`©xyz`、`loci`)。ほかの項目は空にして無効化 |

XMP に書かれた位置情報や、GoPro・ドローンなどの時系列 GPS データは、他の情報と一緒に入っているため残しません。

### 残すもの

- **写真の向き（Orientation）**: 削除すると縦向きの写真が横になって表示されるため、この 1 項目だけを残します。
- **色の情報（ICC プロファイルなど）**: 色が正しく表示されるために必要なデータです。個人を特定する情報は含みません。
- 画像・映像・音声のデータそのもの。再圧縮はしないので、**画質は劣化しません**。

## 対応していないもの・注意点

- RAW（CR2/CR3/NEF/ARW/DNG など）、TIFF、GIF、BMP、AVI、MTS などは処理しません。一覧の「処理対象外のファイル」に表示します。
- `.AAE`（iPhone の編集情報）、`.XMP`、`.THM`、`.XML`、`.LRV` などの付属ファイルにも撮影情報が入っていることがあります。共有するときは含めないでください。
- **ファイル名**（例: `IMG_20240501_102030.jpg`）に撮影日時が入っている場合、ファイル名は変わりません。
- 新しく保存したファイルの更新日時は、保存した時刻になります。
- 写っている内容（顔、風景、看板など）から場所や人物が分かる場合、それはメタデータでは防げません。

## 開発者向け: 動作確認

ffmpeg と exiftool でテスト用の写真・動画を作り、削除後に個人情報タグが残っていないこと、ファイルが壊れていないことを確認します。

```bash
node photo-cleaner/test/verify.mjs
```

HEIC は ffmpeg で作れないため、手元の HEIC ファイルを指定すると検証します。

```bash
HEIC_SAMPLE=/path/to/IMG_0001.HEIC node photo-cleaner/test/verify.mjs
```

### ファイル構成

- `index.html` — 画面
- `app.js` — フォルダの読み込み・保存・ZIP 作成
- `cleaner.js` — メタデータ削除の本体（ブラウザと Node.js の両方で動作）
- `test/verify.mjs` — 動作確認スクリプト
