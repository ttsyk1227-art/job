# 生徒情報管理システム

高校向けの生徒情報管理システムです。生徒の個人写真・クラス名簿・部活動・日常記録(メモ)を
一元管理できます。Next.js (App Router) + Prisma + SQLite で構築しています。

## 主な機能

- **生徒名簿**: クラス・学年ごとの名簿表示、氏名/ふりがな/学籍番号での検索
- **個人写真**: 生徒ごとの写真アップロード・差し替え
- **部活動管理**: 部活動マスタ、部員の追加・削除、顧問の設定
- **日常記録・メモ**: 生活指導・健康・進路・保護者連絡などカテゴリ別の記録をタイムライン表示
- **権限管理**:
  - 管理者(ADMIN): 全データの閲覧・編集、クラス/教員アカウントの管理
  - 教員(STAFF): 自分が担任するクラス、または顧問を務める部活動に所属する生徒のみ閲覧・編集可能

## セットアップ

```bash
npm install
cp .env.example .env   # .env の AUTH_SECRET を openssl rand -base64 32 などで生成した値に変更してください
npx prisma migrate dev --name init
npm run db:seed        # サンプルデータ(教員・クラス・生徒・部活動)を投入
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。未ログインの場合は自動的に
ログイン画面へ移動します。

## データベース

開発環境では SQLite (`prisma/dev.db`) を使用しています。本番運用でユーザー数・データ量が
増える場合は `prisma/schema.prisma` の `datasource` を PostgreSQL 等に変更してください。

## 個人情報の取り扱いについて

生徒の氏名・写真・日常記録は機微な個人情報です。本システムでは以下の対策を行っていますが、
実運用前に学校の個人情報保護方針に沿って追加の対策を検討してください。

- ロールベースのアクセス制御(担任・顧問は自分の関係する生徒のみ閲覧可能)
- パスワードは bcrypt でハッシュ化して保存
- アップロードされた写真・SQLite データベースファイルは Git 管理対象外(`.gitignore` 済み)
- セッションは 12 時間で自動的に失効

追加で検討すべき事項の例:

- 通信の HTTPS 化(本番デプロイ時にリバースプロキシ等で設定)
- 操作ログ(誰がいつ生徒情報を閲覧・編集したか)の記録
- 卒業・退学した生徒データの保管期間ルールと削除フロー
- パスワード変更・リセット機能(現バージョンには未実装)
